# Selection and sources

Checked 2026-10-25. New family: marketing-performance. Existing media-planning covers plans; this build reconciles actual results, measures performance and reviews evidence.

Selected Salesforce Marketing Cloud Intelligence. Current Intelligence+ list price is US$11,000 per organisation per month billed annually, equivalent to US$132,000 a year. The same page lists Marketing Intelligence at US$10,000 per organisation per month billed annually. These are public list prices, not verified NZ/AU customer invoices or an assertion that every existing contract costs this much. [Vendor pricing](https://www.salesforce.com/marketing/analytics/pricing/).

Six scores in order: annual bill 5, data-shaped 5, our buyers 1, search demand 3, one-session buildable 4, import 5. Total 23/30. Customer-brain notes and available CRM context searched locally: no confirmed user or invoice found. No live customer system was accessed. Buyer fit remains unproven. Search results contain dedicated alternative comparisons; keyword volume was not measured.

Runner-up: DefectDojo Pro, vulnerability-remediation family, 2/5/1/3/4/5 = 20/30. [Vendor pricing](https://defectdojo.com/pricing) describes annual pre-pay starting in low four figures monthly and quotes the exact tier. Community Edition already provides a free platform, weakening the ownership comparison. No verified buyer invoice found.

Salesforce [data reports](https://help.salesforce.com/s/articleView?id=mktg.dato_anlyz_reports.htm&language=en_US&type=5) document configurable dimensions, measures, date ranges and CSV. The importer implements an explicitly specified campaign-day report. It has been tested against synthetic fixtures matching that contract; no authenticated tenant export was available.

[Alternatives search evidence](https://www.martechstackbuilder.com/vendors/salesforce-marketing-cloud-intelligence/alternatives/) shows competitors and comparison content, not measured search volume. No claim about a rival's capability is relied on for the build. The vendor already supports dashboards, attribution and automated campaign operations; the free base is a bounded replacement for the exported-results desk, not a recreation of those services.

The published Test Management for Claude Code repo was cloned and read as the quality reference: schema, audits, isolated smoke tests, commands, document outputs and import guide. No customer records or proprietary vendor implementation were copied.
