# Why there is no front end

This base handles the weekly performance desk: import exported results, review exceptions, record a decision and draft the report. A coding agent runs the CLI and explains the records. Read-only HTML gives the owner a review they can print.

A vendor screen provides interactive filtering, charts, drag and drop, role management and connector administration. This base has no mobile app, offline synchronisation, direct ad-platform connections, automatic pausing or live collaboration. It does not reconstruct Salesforce attribution or saved dashboards. The owner chooses what additional screens and connections Enterprise DNA builds into their version.

PGlite works locally without a server. A shared Postgres installation needs authenticated access and operating controls. Backups and secure storage remain the operator's job unless they are part of the managed service.
